## 🚀 COMO COMEÇAR (5 PASSOS)

### Passo 1: Instalar (5 min)

```bash
python install_frt_suite.py
# Responda "s" para continuar
# Sistema se configura automaticamente
```

### Passo 2: Copiar Arquivos Core

```bash
# Copie para ~/.frt_suite/:
cp frt_red_team_suite.py ~/.frt_suite/
cp frt_suite_extensions.py ~/.frt_suite/
```

### Passo 3: Preparar Tokens

```bash
# Coloque arquivo de tokens em um destes locais:
cp captura_tokens.json ~/
# ou
cp captura_tokens.json ~/.frt_suite/data/
```

### Passo 4: Executar

```bash
python ~/.frt_suite/frt_red_team_suite.py
```

### Passo 5: Usar Menu

```
Menu Principal:
  [1] Carregar tokens
  [20] Analisar FRT
  [35] Coleta rápida
  [50] Gerar relatório
```



